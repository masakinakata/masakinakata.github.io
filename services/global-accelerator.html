AWS Global Accelerator

2 つの静的なエニーキャスト IP アドレスを入口に、ユーザーの通信を最寄りのエッジロケーションから AWS グローバルネットワーク経由で最適なリージョンへ届けるサービス。TCP と UDP に対応する。

構成図

仕組みと主な機能

  • 静的エニーキャスト IP：アクセラレーターごとに 2 つの固定 IP が割り当てられる（BYOIP も可）。ファイアウォールの許可リストに登録しやすい。
  • リスナー：受け付けるプロトコル（TCP / UDP）とポートを指定する。
  • エンドポイントグループ：リージョンごとのグループ。トラフィックダイヤルで、そのリージョンに流す割合（0〜100%）を調整できる。
  • エンドポイント：ALB、NLB、EC2 インスタンス、Elastic IP。重みで配分を調整できる。
  • ヘルスチェックと高速なフェイルオーバー。クライアントアフィニティで同じユーザーを同じエンドポイントに固定することもできる。
  • カスタムルーティングアクセラレーター：特定のユーザーを特定の EC2 インスタンス・ポートへ決定的に割り当てる（マルチプレイヤーゲームのマッチングなど）。

CloudFront との比較

観点CloudFrontGlobal Accelerator
プロトコルHTTP / HTTPS、WebSocketTCP、UDP
キャッシュありなし（経路の最適化のみ）
入口の IP可変（DNS 名でアクセス）固定のエニーキャスト IP × 2
主な用途Web コンテンツ・API の配信ゲーム、IoT、VoIP、マルチリージョンの高速フェイルオーバー

試験で狙われるポイント

  • 「UDP」「固定 IP」「DNS キャッシュに左右されないフェイルオーバー」→ Global Accelerator。
  • トラフィックダイヤルを使ったブルー/グリーンデプロイや、リージョン間の段階的な移行も出題される。
  • キャッシュで静的コンテンツを速くしたいなら CloudFront。両者の使い分けがよく問われる。
