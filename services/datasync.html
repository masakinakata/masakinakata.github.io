AWS DataSync

オンプレミスや他クラウドのストレージと AWS のストレージの間で、大量のファイルやオブジェクトを高速に転送・同期するサービス。スケジュール実行、帯域制限、転送データの検証が標準で付いている。

構成図

仕組みと主な機能

  • ロケーション：転送元と転送先。NFS、SMB、HDFS、S3 互換のオブジェクトストレージ、他クラウドのストレージと、S3 / EFS / FSx（各種）の間で転送できる。
  • エージェント：オンプレミスでは VM（VMware / Hyper-V / KVM）として配置する。AWS のストレージ同士の転送ではエージェント不要。
  • タスク：転送の設定。スケジュール実行、帯域制限、フィルター（含める / 除外するパス）、データ検証を指定する。
  • 差分転送：変更されたファイルだけを転送するので、移行期間中に繰り返し同期して最後に切り替えられる。
  • メタデータ（タイムスタンプ、POSIX のアクセス権、NTFS ACL など）を保持できる。
  • VPC エンドポイントを使えば、Direct Connect などのプライベートな経路だけで転送できる。

データ転送サービスの使い分け

サービス用途
AWS DataSyncオンラインでの大量ファイルの移行・定期同期
AWS Storage Gateway移行後もオンプレミスから AWS のストレージを使い続ける（ハイブリッド）
AWS Transfer Family取引先などとの SFTP / FTPS / AS2 でのファイル交換
オフライン転送（物理デバイス）回線が細い・期限が短いなど、ネットワーク経由では間に合わない場合
S3 Transfer Acceleration遠く離れた場所から S3 へのアップロードを高速化

試験で狙われるポイント

  • 「オンラインで大量ファイルを移行」「スケジュール」「整合性の検証」「帯域制限」→ DataSync。
  • 「移行後もオンプレミスから使い続ける」なら Storage Gateway。移行が目的なら DataSync。
  • 転送時間の見積もり：200 TB ÷ 10 Gbps ≒ 約 2 日（理論値）。回線と期限から、オンラインかオフラインかを判断する。
