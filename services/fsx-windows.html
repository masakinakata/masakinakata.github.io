Amazon FSx for Windows File Server

Windows Server 上に構築された、フルマネージドなファイルサーバー。SMB プロトコル、Active Directory 連携、NTFS のアクセス権（ACL）など、Windows のファイル共有の機能をそのまま使える。

構成図

仕組みと主な機能

  • デプロイの種類：シングル AZ / マルチ AZ（自動フェイルオーバー）。
  • ストレージ：SSD（低レイテンシー）または HDD（低コスト）。スループット容量は別に指定する。
  • Windows の機能：NTFS ACL、DFS 名前空間、シャドウコピー（以前のバージョン）、データ重複排除、ユーザークォータなど。
  • バックアップ：毎日の自動バックアップとユーザー起動のバックアップ。AWS Backup でも管理できる。
  • アクセス元：VPC 内の EC2 / WorkSpaces のほか、VPN や Direct Connect 経由でオンプレミスからも使える。
  • 移行：AWS DataSync（ACL やタイムスタンプを保持、スケジュール・検証付き）や Robocopy。

ファイルストレージの使い分け

サービスプロトコル主な用途
Amazon EFSNFSLinux の共有ファイルシステム。容量は自動で伸縮
FSx for Windows File ServerSMBWindows のファイル共有、AD 連携
FSx for NetApp ONTAPNFS / SMB / iSCSIマルチプロトコル、NetApp からの移行、スナップショット / SnapMirror
FSx for LustreLustreHPC・機械学習。S3 と連携
FSx for OpenZFSNFSZFS からの移行、低レイテンシー
S3 File GatewayNFS / SMBオンプレミスから S3 をファイル共有として使う（ハイブリッド）

試験で狙われるポイント

  • 「SMB」「Active Directory」「NTFS ACL」「DFS」→ FSx for Windows File Server。
  • 「AZ 障害でも継続」→ マルチ AZ 構成を選ぶ。
  • EFS は NFS（Linux 向け）、Lustre は HPC 向けで、Windows のファイル共有の要件は満たさない。
  • Windows と Linux の両方から同じデータにアクセスしたい場合は FSx for NetApp ONTAP も候補。
